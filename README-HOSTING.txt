HOSTED DASHBOARD BUILD

Files:
- index.html
- dashboard.css
- dashboard.js
- dashboard-data.json

How to test locally:
1. Unzip package.
2. Open index.html in Chrome, Edge, or Safari.
3. Click the left rail buttons.
4. Confirm the main/right panel changes.

How to host later:
Upload all files in this folder to a private/static host. Use index.html as the entry page.

Safety:
This dashboard does not place broker orders. It is manual-submit only.
