Daily Summary

Follow this order each morning: Gate → Exceptions → Watchlist → Ready Trades → Trades → Alerts → Journal.

🚦 Gate / Lane

Open VectorVest, check MTI, BSR Light, and Color Guard, then log the lane in Notion Gate Log.

Red = no new tactical trades.
Yellow = caution / review only unless all checks pass.
Green = proceed with normal review, still manual-submit only.

🚨 Exceptions

Review rejected orders, missing stops, stale alerts, broker mismatch, duplicate tickers, or unresolved confirmations before new trades.

👀 Watchlist

Current ideas from OptionsPlay 360, Options Alert, Stock Alarm, Pro Ticker, TradingView, OptionsPro, TradeStation, and manual research appear here after capture/review.

✅ Ready Trades

Ready means score/risk/ticket checks passed and Bernard still must manually approve and submit. Ready does not mean submitted.

📈 Trades / Reconciliation

Only broker Filled/Executed confirmation can become Open. Submitted, queued, working, or pending is not Open.

🔔 Alerts / Parsers

Capture examples and parser status for TradingView, Pro Ticker, Options Alert, Stock Alarm, OptionsPlay 360, OptionsPro, and brokers.

🧪 Testing Mode

Testing mode remains active until go-live blockers are cleared. Do not trust parser automation without confirmed examples.

🏛️ Foundation

Foundation portfolio is separate from tactical trading. Do not mix long-term allocations with trade candidates.
